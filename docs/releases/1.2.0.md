# AssegaiPHP Beanstalkd 1.2.0

Status: planned; not yet published.

Beanstalkd 1.2.0 adds Common 0.11 compatibility while retaining Common 0.10.1 support. Its planned artifact is part of the coordinated AssegaiPHP 0.11 release. It preserves the adapter's existing version stream: adapter 1.0 accompanied Common 0.9, and adapter 1.1 accompanied Common 0.10.

## Compatibility

- accepts `assegaiphp/common:^0.10.1 || ~0.11.0`
- recommends Core `~0.11.1` and Console `~0.11.1` when migrating to framework 0.11
- retains PHP 8.4+, Pheanstalk `^7.0`, and the existing queue runtime behavior
- retains the compatible Attributes 1.0 dependency through Common

The retained Common minimum matches the [published 1.1.2 manifest](https://github.com/assegaiphp/beanstalkd/blob/1.1.2/composer.json).

Lazy connections, typed job hydration, delete-on-success and release-on-`Throwable` handling continue to use the existing contracts. The JSON envelope format is unchanged.

## Upgrade notes

Wait until the coordinated packages are published. For a framework 0.11 migration, upgrade the adapter and framework dependencies together:

```bash
composer require "assegaiphp/beanstalkd:~1.2.0" "assegaiphp/common:~0.11.0" "assegaiphp/core:~0.11.1" --with-all-dependencies
```

For that migration, upgrade the Console in the environment where workers run to `~0.11.1`. If the other queue adapter is installed, the coordinated recommendation is `~1.2.0` in the same Composer operation. Preserve stricter or broader supported application requirements and resolve their compatibility before updating.

No queue configuration, job or processor changes are required by this adapter alignment. Applications remaining on Common `^0.10.1` may upgrade the adapter to `~1.2.0` without changing that Common requirement. Common `0.10.0` is below the retained minimum.
